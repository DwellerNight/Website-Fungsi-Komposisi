Apa itu Fungsi Komposisi?

Fungsi komposisi adalah penggabungan operasi dua fungsi secara berurutan yang menghasilkan fungsi baru. Anggap satu fungsi bekerja sebagai masukan bagi fungsi berikutnya.

Hasil Komposisi (f ∘ g)(x)

Pelajari Lebih Dalam

Fungsi komposisi ditulis sebagai (f ∘ g)(x) atau f(g(x)).

Urutan penting: Baca dari kanan ke kiri. Fungsi g dikerjakan terlebih dahulu, kemudian hasilnya menjadi input untuk fungsi f.

Contoh: Jika f(x) = 2x dan g(x) = x + 3, maka f(g(x)) = 2(x + 3) = 2x + 6.

Fungsi komposisi TIDAK komutatif. Artinya, f(g(x)) ≠ g(f(x)) dalam kebanyakan kasus.

Contoh:

  • f(x) = x², g(x) = x + 1
  • f(g(x)) = (x + 1)² = x² + 2x + 1
  • g(f(x)) = x² + 1

Hasilnya berbeda! Urutan sangat penting dalam komposisi fungsi.

Domain dari f(g(x)) adalah semua nilai x yang memenuhi:

  1. x ada di domain g(x)
  2. g(x) ada di domain f(x)

Contoh: Jika f(x) = √x dan g(x) = x - 5, maka domain f(g(x)) adalah x ≥ 5 karena x - 5 ≥ 0.

Salah Urutan Komposisi

Salah: Menganggap f(g(x)) = g(f(x))

Benar: f(g(x)) ≠ g(f(x)) dalam kebanyakan kasus

Urutan komposisi sangat penting. Fungsi yang lebih dalam (di dalam kurung) dikerjakan terlebih dahulu.

close

Lupa Mengganti Semua x

Salah: f(g(x)) = 2x + g(x) jika f(x) = 2x + x

Benar: f(g(x)) = 2g(x) + g(x) = 3g(x)

Setiap kemunculan variabel x dalam f(x) harus diganti dengan g(x) secara lengkap.

close

Mengabaikan Tanda Kurung

Salah: Jika g(x) = x + 1, maka g(x)² = x + 1²

Benar: g(x)² = (x + 1)²

Selalu gunakan tanda kurung saat mensubstitusi fungsi untuk menghindari kesalahan operasi.

close

Salah Menghitung Domain

Salah: Domain f(g(x)) = domain f(x)

Benar: Periksa domain g(x) DAN pastikan g(x) ada di domain f

Domain komposisi harus memenuhi syarat kedua fungsi, bukan hanya fungsi luar.

Penerapan

Fungsi Komposisi di Dunia Nyata

Konsep ini tidak hanya teori — fungsi komposisi digunakan dalam berbagai bidang teknologi dan sains.

computer

Grafik Komputer

Transformasi objek 3D menggunakan komposisi fungsi untuk rotasi, translasi, dan scaling. Setiap transformasi adalah fungsi yang dikomposisikan secara berurutan.

Transform(Rotate(Scale(object)))
psychology

Machine Learning

Neural networks adalah komposisi fungsi berlapis. Setiap layer menerapkan fungsi aktivasi pada output layer sebelumnya.

σ(W₃·σ(W₂·σ(W₁·x)))
transform

Transformasi Data

Pipeline pemrosesan data menggunakan komposisi fungsi untuk membersihkan, mengubah, dan menganalisis data secara bertahap.

analyze(filter(normalize(data)))
encrypted

Kriptografi

Algoritma enkripsi menerapkan beberapa fungsi transformasi secara berurutan untuk mengamankan data.

encrypt₃(encrypt₂(encrypt₁(message)))
photo_filter

Image Processing

Filter gambar diterapkan secara berlapis — brightness, contrast, blur — masing-masing adalah fungsi yang dikomposisikan.

blur(contrast(brightness(image)))
functions

Functional Programming

Paradigma pemrograman yang menggunakan komposisi fungsi sebagai konsep inti untuk membangun program yang modular.

compose(map, filter, reduce)
